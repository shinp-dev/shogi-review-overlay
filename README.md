# Shogi Review Overlay

将棋ウォーズなどの**対局後の振り返り画面**に、候補手を重ねるAndroidアプリ（試作版）。

## 現在できること
- Android 10以降で表示権限を取得し、将棋アプリの上に透過オーバーレイを表示
- 9×9盤面の位置をドラッグ移動・右下ハンドルでサイズ調整（縦横を独立して合わせられる）
- SFEN入力から最大3候補を計算して、盤面上に緑・青・橙の矢印と参考スコアを表示
- 持ち駒の打ち手を含むSFEN解析、棋譜の指し手表記、候補一覧を表示
- 候補数（1〜3）、矢印／候補一覧、文字サイズを設定
- 普段のオーバーレイはタッチ透過、盤面調整モードだけタッチ入力

## 重要な制限（2026-11-23時点）
- **画面からの自動駒認識は未実装**です。現時点ではSFENを手動で入力して候補を表示します。
- **やねうら王／評価関数は未搭載**です。内蔵の浅い簡易探索は画面と配置確認用であり、実戦的な最善手・正確な評価値を保証しません。表示スコアは「簡易参考値」です。
- 対局中か振り返り中かを機械的に判別する機能はありません。対局中に起動しないでください。
- 一部の持ち駒・成り・二歩チェックを実装。打ち歩詰め等の例外的な禁手の検証は未完了です。
- Android端末での実機ビルド／動作検証はまだ完了していません。

## ビルド
JDK 17 と Android SDK API 35、Gradle 8.9 が必要です。

\`\`\`bash
gradle :app:assembleDebug
gradle :app:testDebugUnitTest
\`\`\`

成果物は \`app/build/outputs/apk/debug/app-debug.apk\`。

## 使い方
1. アプリを起動し「他のアプリの上に表示」を許可する。
2. 将棋ウォーズの振り返りを表示したまま、本アプリで「位置調整」を開始。盤面のグリッドを合わせて「完了」。
3. 本アプリのSFEN欄に解析したい局面を入力し、「候補を計算・表示」。
4. 将棋ウォーズ側の局面を1手進めたら、対応するSFENを更新して再計算する（現段階では自動追従しません）。
5. 終了時は「オーバーレイ停止」を押す。

初期局面のSFEN: 
\`lnsgkgsnl/1r5b1/ppppppppp/9/9/9/PPPPPPPPP/1B5R1/LNSGKGSNL b - 1\`
