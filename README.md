# Shogi Review Overlay

将棋ウォーズなどの**対局後の振り返り画面**に、候補手を重ねるAndroidアプリ（試作版）。

## 実装済み（v0.4.3・試験中）

- AndroidのMediaProjection許可で画面全体を取得し、各マスの外周8%を除外して32×32白黒画像比較。上下左右それぞれ最大4pxの盤面位置ズレを自動探索・補正
- 設定画面で**将棋ウォーズ／将棋クエスト**を選択。盤面位置・補正値はアプリ別に保存し、各アプリ専用の駒画像テンプレートを利用
- 盤面を9×9に手動調整。クエストは上下各9候補枠の金色の駒形を検出、ウォーズは上下最大7枠のオレンジの駒形を検出。駒がある枠内だけで駒種・先後・枚数を判定し、持ち駒が復元できなければ従来どおり1手差分で追跡
- やねうら王 MaterialLv1 のAndroid arm64-v8a向け実行ファイルと対応ソースをリポジトリに同梱し、APKに格納
- USI MultiPV=1〜3で候補と評価値を取得し、緑/青/橙の盤面矢印と候補一覧に表示
- 将棋ウォーズ・将棋クエストともに成駒6種類×先後2方向の画像照合に対応。ウォーズは後手向き全6種、クエストは後手向き馬以外5種が回転画像による暫定テンプレート。通常駒は以前のテンプレートも併用
- SFEN手入力による補正、文字サイズ・思考時間などの設定
- 通常時はタップ透過で、緑色の盤面外枠は候補手がないときや画面取得中も表示。画面取得時は盤上を覆う候補手の矢印やラベルを一時的に隠す。

## 注意事項

- やねうら王は**Material評価版**。NNUE評価関数は未搭載で、候補の質は高性能版と同等ではない。
- 画像比較の実機認識率とMediaProjectionの操作動作はまだ未検証。両アプリとも基本駒16種＋成駒12種を照合するが、持ち駒が多数ある局面、複数手飛ばしはSFEN手動補正が必要な場合がある。
- 将棋クエストは提供された2枚の振り返り画像で、通常駒34枚と成駒を含む32枚の認識を回帰テスト。さらに提供された3枚の画像から上下各9候補枠の金色画素だけを抽出し、**離れた位置に並ぶ持ち駒も含めて位置認識を検証**。枚数の赤い数字は**2〜9が実画像由来**、0・1のみ合成テンプレートで未検証（誤認識防止のため直接判定から除外）。数字の判定に失敗しても、盤上の不足駒と持ち駒の所有者から枚数が一意に決まるときだけ補完する。駒種別の40枚が整合しなければ解析を見送り、一手差分追跡に戻る。別テーマ・実機・未撮影の後手成駒は未検証。
- 将棋ウォーズの持ち駒画像認識は初期対応。実画像から確認した後手の角・歩と先手の歩・香・金、黄色い枚数2・3・4・6を実画像から登録済み。未収集の持ち駒や別テーマは検出できない場合があり、駒種別の総数が40枚と一致しなければ途中局面として採用しない。実機では未検証。
- **対局後の振り返り専用**。投了ボタン検出による停止は廃止しました。対局中/振り返り画面の判別は行わないため、対局中には起動しないでください。
- スクリーンショットは端末からアップロードしない設計。
- GPLv3ライセンスと上流の対応ソース提供条件について、配布前の整合性確認が必要。

詳しくは docs/ENGINE.md と docs/RECOGNITION.md を参照。

## ビルド
JDK 17・Git・Android SDK API 35 が必要です。Windows/Linuxとも Gradle Wrapper (8.9) でビルドできます。Android SDKの利用許諾は事前に済ませてください。やねうら王のARM64実行ファイル・対応ソース・認識モデルはGit管理下に同梱済みです。Gradleは同梱バイナリをSHA-256で検証してAPKに格納します。NDK、上流からのエンジン取得、ネイティブコンパイル、GitHub Actionsは通常ビルドに不要です。

Windowsで実機にインストール:

```bat
gradlew.bat :app:installDebug
```

Linuxでは `./gradlew :app:installDebug`。APKのみ生成する場合は `:app:assembleDebug`、単体テストは `:app:testDebugUnitTest`。初回からリポジトリ同梱の実行ファイルを利用します。欠落・破損時には外部から取得せず、ビルドを中止します。通常のGradle・Android SDK依存関係は別途必要です。

成果物は `app/build/outputs/apk/debug/app-debug.apk`。GitHub ActionsではWindows/LinuxのクリーンビルドとAPK内エンジンの検証を行います。

## 使い方

1. 設定画面で将棋ウォーズ／将棋クエストを選択する。
2. 「盤面解析を開始」を押す。初回は他のアプリの上に表示する権限、毎回は画面全体の共有を許可する。
3. 対象アプリの対局後の振り返り画面に移動する。初期位置の緑枠と操作パネルが表示される。
4. 位置がずれている場合はパネルの「枠調整」を押し、枠を合わせて「調整完了」。認識が進まないときは「解析」を押す。
5. 終了時は操作パネルの「終了」で画面共有・枠・候補表示をまとめて停止する。設定画面の「すべて停止」も同じ動作。
6. SFENの手入力は「SFEN手動解析」、表示テスト・認識の外周除外設定は「詳細設定・動作確認」を開く。

### 緑枠すら表示されない場合
- **盤面位置が未設定だからではない**。まず「詳細設定・動作確認」の「枠だけ表示」の独立テストで解析・画面取得と切り分ける。
- 「枠の表示状態を確認」で `枠のウィンドウ作成成功` と出るのに対象アプリで見えない場合、対象アプリまたはOSによるオーバーレイ非表示の可能性がある。対象アプリを閉じたホーム画面上でもテストする。
- `表示権限なし`／`枠の表示に失敗` なら端末設定・エラー表示を確認する。
- 画面共有を開始すると調整用のグリッドを閉じ、タップを透過する緑枠に切り替える。画面取得時も緑枠を表示し、表示サービスの再起動でウィンドウが失われた場合は再作成する。
