# Shogi Review Overlay

将棋ウォーズなどの**対局後の振り返り画面**に、候補手を重ねるAndroidアプリ（試作版）。

## 実装済み（v0.3.0・試験中）

- AndroidのMediaProjection許可で画面全体を取得し、81マスの内側84%を32×32モノクロ化し、横縦の黒画素数と画素配置で駒を画像比較
- 盤面を9×9に手動調整し、前局面との合法手1手の差分による持ち駒追跡
- やねうら王 MaterialLv1 をAndroid arm64-v8a向けにビルドしてAPKへ同梱
- USI MultiPV=1〜3で候補と評価値を取得し、緑/青/橙の盤面矢印と候補一覧に表示
- SFEN手入力による補正、文字サイズ・思考時間などの設定
- 通常時はタップ透過、調整画面のみタップを取得、画面取得/認識失敗時は候補を消去

## 注意事項

- やねうら王は**Material評価版**。NNUE評価関数は未搭載で、候補の質は高性能版と同等ではない。
- 画像比較の実機認識率とMediaProjectionの操作動作はまだ未検証。現在は基本の先後16種類の駒テンプレートのみで、成駒や持ち駒が多数ある局面、複数手飛ばしはSFEN手動補正が必要な場合がある。
- **対局後の振り返り専用**。対局中の利用はしないでください。対局/振り返り画面の自動判別は未実装です。
- スクリーンショットは端末からアップロードしない設計。
- GPLv3ライセンスと上流の対応ソース提供条件について、配布前の整合性確認が必要。

詳しくは docs/ENGINE.md と docs/RECOGNITION.md を参照。

## ビルド
JDK 17・Android SDK API 35・Gradle 8.9、Native版をビルドする場合はAndroid NDK r23bが必要です。GitHub Actionsは同梱まで実施します。

```bash
gradle :app:assembleDebug
gradle :app:testDebugUnitTest
```

成果物は `app/build/outputs/apk/debug/app-debug.apk`。

## 使い方

1. インストール後、他のアプリの上に表示する権限を許可する。
2. 将棋ウォーズの対局後振り返りで盤面位置を手動調整する。
3. アプリで「盤面を自動認識・解析」を押し、Androidの画面全体の共有を許可する。
4. 将棋ウォーズの振り返りを開いたまま局面を1手ずつ進める。3候補を再解析する。
5. 認識に失敗した場合、設定画面の最新ステータスを確認し、必要ならSFENを手動入力して再解析する。
6. 終了したら「自動認識を停止」と「オーバーレイ停止」を押す。
