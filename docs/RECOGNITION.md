# 将棋ウォーズの盤面自動認識

## 実装
1. ユーザーが画面共有を許可すると、ReviewCaptureService はMediaProjectionで約4.5秒間隔でフレームを取得する。画像は保存・送信せず、端末内で処理する。
2. 盤面調整済みの9×9セルを切り出し、通常と180度回転の2画像の日本語OCRアトラスを作る。ML Kitで駒種・成り・向きを分類する。
3. 王将の数、盤上駒数、総駒数、OCR曖昧判定を検証する。誤認識・未確定時は候補表示を消す。
4. 盤上40枚（持ち駒なし）と、盤上39枚＋下側に1持ち駒を視認できる一部の局面を直接SFEN化する。
5. 一度確定した局面の直後なら、合法手1手に一致する盤面へ遷移したことを照合し、捕獲した持ち駒の保持も復元する。
6. 推定SFENをUsiEngineへ渡し、やねうら王Material版のMultiPVで候補3手を計算する。

## 未完了・制限
- OCRの将棋ウォーズ実機認識率は未計測。今後フォント・成駒・持ち駒の多い局面を画像セットで評価する必要がある。
- 途中局面で複数の持ち駒がある場合や、レビューで複数手飛ばした場合は自動確定できないことがある。そのときは手入力SFENで修正する。
- 現段階は画面下が先手の盤面向き専用。手番は設定で選び、移動追跡できる場合は自動切替される。
- 対局中と振り返り画面の自動判定は未実装。**対局中に実行しないこと**。
- 画面共有は画面全体を選ぶ。アプリ単位共有では表示位置がずれる場合がある。
- ImageReader/MediaProjectionとオーバーレイの透過動作は実機確認が必要。

## 動作確認
1. 将棋ウォーズを対局後の振り返り画面で開き、盤面を手動調整する。
2. アプリから画面全体の共有を許可し、振り返り画面に戻る。
3. 初期局面と1手進めた局面で、3候補が新しい局面に更新されるか確認する。
4. 取る手・成り・持ち駒でSFENが合っているか確認する。
5. 認識失敗時に古い候補が消えるか確認する。
6. 長時間、機種別解像度、画面回転、復帰・停止時の権限やメモリを確認する。
